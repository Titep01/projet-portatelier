# Projet Portatelier

> [!IMPORTANT]
> **À modifier** : ce repo a été créé depuis le template de projet du MakerSpace d'Amiens.
> Remplacez ce README par la présentation de votre projet.
> Les guides d'utilisation du template sont sur le
> [site de documentation du MakerSpace](https://doc.makerspace-amiens.fr/workshops/methodologie-de-projet/).

Ce projet vise à créer un système modulaire afin de transporter tout le matériel nécessaire à un projet extérieur.
Initialement prévue dans le cadre de la coupe de France de robotique  (CDR 2027) organisée par Planet Science et Eurobot. Le but à terme sera de présenter un version open-source avec les modules de base, les instructions de création, ainsi que la documentation ci-jointe.

- **Documentation :** [site du projet](https://titep01.github.io/projet-portatelier/)
